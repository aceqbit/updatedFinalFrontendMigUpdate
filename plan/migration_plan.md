This repository's master migration index lists the single, atomic migration plan for the final Angular upgrade: v20 → v21.

- Target: Angular 20 → 21 (only)
- Primary plan file: plan/migration_v20_to_v21.md
- Goal: Produce deterministic, atomic migration with build/test validation and a single authoritative commit checkpoint on `main`.

Sequence (high level):
1. Assessment: `report/assessment_report.md` (generated by the Assessment Agent)
2. Planning: `plan/migration_v20_to_v21.md` (this plan)
3. Implementation: `report/implementation_log.md` (generated during execution)
4. Unit testing: `report/test_report.md`
5. Documentation: `docs/documentation.md`
6. Final report: `report/migration_report.md`

Notes:
- Checkpoint policy: use commit-only checkpoints on `main` (e.g., `chore(migration): complete Angular v21`). Do NOT use tags as authoritative checkpoints.
- All steps must follow the project's agent policies (append-only updates, automatic selection of optional prompts, Windows clean-workspace steps when needed).
